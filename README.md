# 🛍️ GrocerPy 
### CLI-Based Retail Point of Sale & Invoice Generator

**GrocerPy** is a lightweight, interactive Point of Sale (POS) and billing system built entirely using **Core Python**. Designed to run directly in the terminal, it allows users to browse product categories, manage shopping carts, calculate taxes automatically, and generate professional receipts.

---

## 🚀 Features

* **Interactive Categories:** Browse through multiple product sections including Fruits, Vegetables, Dairy, Snacks, and Beverages.
* **Smart Cart Management:** Add items with custom quantities and check inputs securely.
* **Automated Calculations:** Automatically computes subtotal, applies a **5% GST**, and generates the final grand total.
* **Text Receipt Generation:** Automatically saves a clean, formatted copy of the customer invoice as a `.txt` file.
* **Robust Error Handling:** Built with exception handling (`try-except`) to prevent program crashes on invalid inputs.
* **Terminal UI Styling:** Uses ANSI color codes and emojis for a visually appealing command-line experience.

---

## 💻 Tech Stack
* **Language:** Core Python (3.x)
* **Concepts Used:** Dictionaries, Loops, Conditional Statements, Functions, Exception Handling, File I/O.
